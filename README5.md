# Практическая работа № 5. Классификатор и анализ метрик

**Цель работы:** построить модель бинарной классификации, оценить её качество с помощью метрик классификации и проанализировать типы ошибок с учётом особенностей задачи.

**1. Подготовка данных**

Для эксперимента использован датасет с двумя классами и умеренным дисбалансом между ними. Данные разделены на обучающую и тестовую выборки. Предобработка выполнена с учётом типов признаков и без использования информации из тестовой выборки при обучении преобразований.

**2. Обучение классификатора**

Для построения модели использован алгоритм логистической регрессии `LogisticRegression` из библиотеки `scikit-learn`. Модель обучена на тренировочной выборке и используется для предсказания класса объектов тестовой выборки.

**3. Матрица ошибок**

Для сопоставления фактических и предсказанных классов построена матрица ошибок (confusion matrix). Она позволяет определить количество правильных и неправильных классификаций.

- **TP (True Positive)** — положительные объекты, правильно предсказанные как положительные.
- **TN (True Negative)** — отрицательные объекты, правильно предсказанные как отрицательные.
- **FP (False Positive)** — отрицательные объекты, ошибочно предсказанные как положительные.
- **FN (False Negative)** — положительные объекты, ошибочно предсказанные как отрицательные.

**4. Оценка качества классификации**

Для оценки модели использованы следующие метрики:

- **Accuracy** — доля правильных предсказаний среди всех объектов.
- **Precision** — доля действительно положительных объектов среди предсказанных положительными.
- **Recall** — доля найденных положительных объектов среди всех фактически положительных.
- **F1-score** — гармоническое среднее Precision и Recall.

Выбор основной метрики зависит от цены ошибок в конкретной задаче. Если особенно опасно пропустить положительный объект, приоритет отдаётся Recall.
