# Практическая работа № 3. Сборка пайплайна предобработки

**Цель работы:** создать пайплайн предобработки данных с использованием библиотеки `scikit-learn`, включающий обработку пропусков, кодирование категориальных признаков и масштабирование числовых данных без утечки информации из тестовой выборки.

**1. Разделение данных**

Данные разделены на обучающую и тестовую выборки с помощью функции `train_test_split()`. Для тестовой выборки используется доля 0,2 (20%), а для обучающей — 0,8 (80%). Такое разделение позволяет оценивать качество обработки на данных, которые не участвовали в обучении преобразований.

**2. Обработка пропусков**

Для заполнения пропущенных значений числовых признаков используется `SimpleImputer(strategy="median")`. Медиана вычисляется на обучающей выборке и затем применяется для заполнения пропусков в обучающих и тестовых данных.

**3. Кодирование категориальных признаков**

Для преобразования категориального признака используется `OneHotEncoder(handle_unknown="ignore")`. Метод создаёт отдельные бинарные признаки для категорий. Параметр `handle_unknown="ignore"` позволяет обрабатывать категории, которые встречаются в тестовой выборке, но отсутствовали при обучении кодировщика.

**4. Масштабирование числовых признаков**

Для масштабирования применяется `StandardScaler`. Он преобразует числовые признаки с учётом среднего значения и стандартного отклонения, вычисленных на обучающей выборке. Это позволяет привести признаки к сопоставимому масштабу.

**5. Сборка пайплайна**

Шаги предобработки объединены с помощью `Pipeline`. Для последовательного применения разных преобразований к числовым и категориальным столбцам используется `ColumnTransformer`. Пайплайн обучается только на обучающей выборке, а затем применяется к тестовой.

**6. Проверка результата**

После преобразования выведены формы матриц признаков `X_train` и `X_test`. Количество столбцов в матрицах должно совпадать, поскольку обучающая и тестовая выборки обрабатываются одним и тем же обученным преобразователем.

**7. Вывод**

В ходе практической работы собран пайплайн предобработки данных с использованием `scikit-learn`. Реализованы разделение выборки, заполнение числовых пропусков медианой, кодирование категориальных признаков и масштабирование числовых данных. Применение пайплайна позволяет последовательно выполнять преобразования и предотвращать утечку информации из тестовой выборки в обучающую.
