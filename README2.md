# Практическая работа № 2. Разведочный анализ данных (EDA)

**Цель работы:** освоить основные методы разведочного анализа данных (EDA), включая описательную статистику, визуализацию распределений, выявление пропусков и выбросов, а также анализ структуры признаков.

**1. Загрузка данных**

Для выполнения работы использован учебный датасет, предоставленный преподавателем. Данные загружены в таблицу `df` с помощью библиотеки `pandas`. Для первичного ознакомления со структурой данных использована команда `df.info()`.

**2. Проверка пропущенных значений**

Для выявления пропусков применена команда `df.isnull().sum()`, которая подсчитывает количество отсутствующих значений в каждом столбце. Результаты проверки позволяют определить признаки, требующие дополнительной обработки.

**3. Анализ распределения числового признака**

Для изучения распределения числового признака построена гистограмма. Она позволяет оценить частоту встречаемости значений, форму распределения и возможную асимметрию данных. Дополнительно использован метод `df.describe()` для получения среднего значения, стандартного отклонения, квартилей, минимума и максимума.

**4. Выявление выбросов**

Для поиска потенциальных выбросов построена диаграмма размаха (boxplot). На ней отображаются медиана, первый и третий квартили, а также точки, находящиеся за пределами стандартных границ диаграммы. Обнаруженные точки требуют дополнительного анализа, поскольку они могут отражать как ошибки данных, так и реальные редкие наблюдения.

**5. Анализ категориального признака**

Для изучения категориального признака построена столбчатая диаграмма частот. Она позволяет сравнить количество наблюдений в разных категориях и определить наиболее часто встречающиеся значения.

**6. Итоговая таблица проблем данных**

По результатам разведочного анализа составляется таблица «Проблема данных — где обнаружена». В ней фиксируются выявленные пропуски, потенциальные выбросы, особенности распределений и другие замечания к качеству данных. Наличие каждой проблемы подтверждается результатами проверок и визуализацией.

**7. Вывод**

В ходе практической работы выполнен разведочный анализ учебного датасета. Изучена структура таблицы, проверено наличие пропусков, исследовано распределение числового признака и построена диаграмма размаха для выявления потенциальных выбросов. Также проведён анализ частот категориального признака. Полученные результаты помогают оценить качество данных и определить, какие этапы предварительной обработки могут потребоваться перед дальнейшим анализом или построением моделей машинного обучения.
