Для эксперимента использован учебный корпус из 600 русскоязычных текстов отзывов. Он содержит три класса: положительные, нейтральные и отрицательные — по 200 текстов каждого класса.

Данные разделены на обучающую выборку (80%, 480 текстов) и тестовую выборку (20%, 120 текстов). Для сохранения пропорций классов использован параметр `stratify`.
