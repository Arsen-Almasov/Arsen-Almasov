# Практическая работа № 4. Регрессионная модель
**Цель работы:** построить модель линейной регрессии, оценить качество её предсказаний и интерпретировать коэффициенты модели с использованием метрик MAE, RMSE и R².

**1. Подготовка данных**

Для эксперимента использованы данные с числовой целевой переменной. Данные загружены и подготовлены для обучения модели. При необходимости выполнены обработка пропусков, кодирование категориальных признаков и масштабирование числовых признаков. Обучающая и тестовая выборки разделены до обучения преобразований.

**2. Обучение модели**

Для построения модели использован алгоритм линейной регрессии `LinearRegression` из библиотеки `scikit-learn`. Модель обучена на тренировочной выборке с помощью метода `fit()`. При обучении модель определяет коэффициенты, описывающие линейную зависимость целевой переменной от входных признаков.

**3. Получение предсказаний**

После обучения модели получены прогнозы для тестовой выборки с помощью метода `predict()`. Предсказанные значения сопоставлены с фактическими значениями целевой переменной для оценки качества модели на данных, не участвовавших в обучении.

**4. Оценка качества модели**

Для оценки использованы следующие метрики:

- **MAE (Mean Absolute Error)** — средняя абсолютная ошибка предсказаний.
- **RMSE (Root Mean Squared Error)** — квадратный корень из средней квадратичной ошибки, чувствительный к большим отклонениям.
- **R² (коэффициент детерминации)** — показатель того, насколько хорошо модель объясняет изменчивость целевой переменной.
